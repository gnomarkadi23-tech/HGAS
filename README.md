# HGapp
An application for quickly downloading apps and programs with a single click.
It can be helpful when installing a new operating system, and it also offers great convenience.
You definitely need Winget.
To check if you have it, open cmd and type `winget --version`.

!Just go in releases and download source code (zip or tar.gz).The app is inside the zip!
